# Full-brain store page

The [store description](../.slop/description.md) introduces the current reference simulation, its learning rule, and the experiments a visitor can watch. The [reference verification](66-expanded-reference-verification.md) records the neuron and cell type counts. SLAPorSLOP stores the description in its page editor. The Markdown file contains the text for that field.

The [gallery manifest](../.slop/media.json) lists three unedited 1600 × 900 captures from the desktop viewer. Each game started from its own copy of the same developed seed-0 checkpoint with 18,944 neurons and 187 populations. The captures show Signal turn 35, Danger turn 8, and Forage turn 12 with learning on. The [title illustration](../.slop/title.png) was generated from the Forage capture. The gallery shows the actual simulation output.

To apply the assets to the existing listing, save the description in **Edit store page** and select **Check my repository now**. SLAPorSLOP pins the images to the checked commit and reviews the new set before displaying it.
