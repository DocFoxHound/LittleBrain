A picture flashes and four buttons light up. Which one will the character press? LittleBrain is an open-source brain simulator that lets you watch a choice unfold. Its current reference brain has 18,944 simulated neurons representing 98 cell types. Pause the live map, hover over a cell to inspect it, and compare what the character saw with the action it took.

Many AI models learn by sending an error signal backward through layers of a network. LittleBrain learns while it plays. When an outcome is better or worse than expected, a change in simulated dopamine helps adjust connections between recently active cells. During sleep, the brain replays recent activity and can even change which cells connect.

Start with the signal game, where each picture has a rewarding button. Then watch what happens when hiding is an option, or when hunger changes the value of food. You can switch learning off and compare how the same brain plays.
